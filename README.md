# Pleer1-Next

Изолированная облачная лаборатория ИИ-компаньона для разработки Pleer1.

## Главная цель

Создать помощника, который изучает архитектуру проекта, объясняет код, ищет причины ошибок, предлагает решения и помогает с реализацией. Независимый Alibaba Open Code Review дополняет его проверкой изменений.

## Границы безопасности

- Этот репозиторий не является исходником приложения Pleer1.
- Не подключать сюда автоматическую запись в `Pleer1`, `Pleer1-UI` или `Pleer1-Lab`.
- Не копировать, не переносить и не изменять рабочие проекты без отдельного явного решения.
- Облачный агент по умолчанию работает только на чтение.
- Любые изменения сначала делаются в отдельной ветке этого репозитория.
- Никаких автоматических merge, push в основные репозитории, релизов или публикации IPA.
- Секреты, токены, cookies, приватные ключи и персональные данные нельзя помещать в Git или передавать в запросах к агенту.

## Облачный прототип

- `opencode.json` — конфигурация read-only агента OpenCode и его разрешений.
- `.github/workflows/cloud-companion.yml` — ручной запуск OpenCode в GitHub Actions.
- Модель `qwen3:4b` загружается во временную Ollama на GitHub-hosted runner; отдельный LLM API-ключ не требуется.
- Ответ сохраняется как GitHub Actions artifact на 7 дней.
- Агенту запрещены запись, shell-команды, сетевые инструменты и чтение файлов `.env`.
- Запуск только вручную, никаких автоматических триггеров.

## Независимое ревью

- `.github/workflows/ocr-review.yml` — прежний ручной workflow OCR в режиме прямого обращения к LLM provider; он пока требует отдельной настройки credentials.
- Следующий этап — подключить OCR delegation mode, чтобы OpenCode выполнял интеллектуальную часть ревью без отдельного OCR API-ключа.

## Текущий статус

Облачный прототип подготовлен в отдельной ветке и ещё не проверен реальным запуском. Пока не считать его работающим до успешного workflow run и проверки отчёта.
