# Pleer1-Next

Изолированная облачная лаборатория самостоятельного ИИ-компаньона для инженерной работы.

## Главная цель

Создать помощника, который изучает архитектуру проекта, объясняет код, ищет причины ошибок, предлагает решения и помогает с реализацией. Независимое ревью должно дополнять, а не заменять компаньона.

## Границы безопасности

- Этот репозиторий — отдельная лаборатория, а не исходник приложения Pleer1.
- Не подключать сюда автоматическую запись в `Pleer1`, `Pleer1-UI` или `Pleer1-Lab`.
- Не копировать, не переносить и не изменять рабочие проекты без отдельного явного решения.
- Облачный агент по умолчанию работает только на чтение.
- Любые изменения сначала делаются в отдельной ветке этого репозитория.
- Никаких автоматических merge, push в основные репозитории, релизов или публикации IPA.
- Секреты, токены, cookies, приватные ключи и персональные данные нельзя помещать в Git или передавать в запросах к агенту.

## Облачный прототип

- `opencode.json` — конфигурация read-only агента OpenCode.
- `.github/workflows/cloud-companion.yml` — запуск компаньона в GitHub Actions.
- Модель: `qwen3:4b-instruct`, запускается через Ollama на временном GitHub-hosted runner.
- Внешний платный LLM API и отдельный API-ключ модели не используются.
- Ответ сохраняется как GitHub Actions artifact на 7 дней.
- Агенту запрещены запись, shell-команды, сетевые инструменты и чтение файлов `.env`.

## Результаты модельной диагностики

- Qwen3 Thinking 4B и Qwen3 Instruct 4B проверены на одинаковом запросе.
- Instruct вернула ровно `ГОТОВО` за 5 токенов; Thinking поместила рассуждения в текст ответа.
- Обе модели успешно сформировали вызов тестового инструмента `get_weather`.
- Следующий этап — проверить реальный цикл OpenCode с Instruct, включая чтение файлов и подготовку отчёта.

## Независимое ревью

- `.github/workflows/ocr-review.yml` — прежний ручной workflow OCR в режиме прямого обращения к LLM provider; он требует отдельной настройки credentials.
- Возможное следующее направление — OCR delegation mode, чтобы OpenCode выполнял интеллектуальную часть ревью без отдельного OCR API-ключа.

## Текущий статус

Модель Instruct выбрана для следующего эксперимента. Полноценная работа OpenCode с ней ещё не подтверждена до успешного запуска и проверки отчёта.
