# Pleer1-Next

Изолированная лаборатория ИИ-компаньона для разработки Pleer1.

## Главная цель

Создать помощника, который умеет изучать архитектуру проекта, объяснять код, искать причины ошибок, предлагать решения и помогать с реализацией. Отдельный ревизор Open Code Review будет проверять изменения независимо.

## Границы безопасности

- Этот репозиторий не является исходником приложения Pleer1.
- Не подключать сюда автоматическую запись в `Pleer1`, `Pleer1-UI` или `Pleer1-Lab`.
- Не копировать, не переносить и не изменять рабочие проекты без отдельного явного решения.
- По умолчанию агент работает в режиме чтения и анализа.
- Любые изменения сначала делаются в отдельной ветке этого репозитория.
- Никаких автоматических merge, push в основные репозитории, релизов или публикации IPA.
- Секреты, токены, cookies, приватные ключи и персональные данные нельзя помещать в Git.

## Состав

- `AGENTS.md` — обязательные правила для coding agents.
- `docs/ARCHITECTURE.md` — план архитектуры компаньона.
- `.github/workflows/ocr-review.yml` — ручной, read-only запуск Alibaba Open Code Review. Требует отдельной настройки LLM secrets/variables.

## Текущий статус

Это безопасный каркас. ИИ-агент ещё не подключён, модель не выбрана, секреты не настроены. Ничего не запускается автоматически.
